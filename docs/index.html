1. Bảng so sánh Máy cá nhân và GitHub Codespace

Tiêu chí Máy cá nhân Codespace
Thời gian từ lúc bắt đầu đến khi chạy được node -v ~ 15 - 30 phút (tải installer, cài đặt, cấu hình PATH) ~ 10 - 20 giây (tự động có sẵn Node.js qua devcontainer)
Số CPU, RAM (từ API) Tùy máy (Ví dụ: 8 CPUs, 16.0 GB) 2 CPUs, 8.0 GB (Standard 2-core codespace)
Hệ điều hành Windows 11 / macOS Linux (Linux 6.x / Ubuntu container)
Cách truy cập từ thiết bị khác Phức tạp (Cần mở Port Router, NAT, hoặc cài ngrok / Cloudflare Tunnel) Dễ dàng (Đổi Port Visibility sang Public → Mở URL *.app.github.dev)
Chi phí, đo bằng gì Tiền điện, khấu hao phần cứng (đo bằng kWh, VNĐ) Tính theo thời gian sử dụng thực tế (đo bằng Core-hours và GB-Month trong GitHub Billing)

2. Ghép 5 đặc tính NIST với trải nghiệm thực tế

  • Tự phục vụ theo yêu cầu (On-demand self-service): Nhấp chuột vào "Create codespace on main" để khởi tạo ngay lập tức môi trường máy ảo đầy đủ mà không cần thông qua sự phê duyệt hay can thiệp thủ công từ quản trị viên.
  • Truy cập mạng rộng (Broad network access): Truy cập và thao tác trên IDE Web Codespace qua trình duyệt máy tính, đồng thời test API cổng 3000 công khai trực tiếp từ trình duyệt trên điện thoại thông minh qua mạng 4G/Wi-Fi.
  • Gộp tài nguyên (Resource pooling): Máy ảo Codespace được cấp phát linh hoạt từ hạ tầng đám mây dùng chung của GitHub/Azure, chạy trên các máy chủ vật lý phục vụ đồng thời nhiều người dùng khác nhau.
  • Co giãn nhanh (Rapid elasticity): Dễ dàng thay đổi cấu hình máy ảo (ví dụ: nâng từ 2-core lên 4-core hoặc 8-core) hoặc mở/tắt Codespace nhanh chóng tùy theo nhu cầu tải công việc.
  • Dịch vụ đo lường được (Measured service): Hệ thống ghi nhận chính xác dung lượng lưu trữ (GB) và số giờ máy hoạt động (Core-hours) hiển thị chi tiết trong trang Settings → Billing → Usage của tài khoản GitHub.
