1. Bảng so sánh thông số (Máy cá nhân vs Codespace)

Tiêu chí Máy cá nhân Codespace (Đám mây)
Thời gian khởi động môi trường ~ vài giây (có sẵn) ~ 30-45 giây
Số CPU, RAM (Ví dụ: 8 CPUs, 16 GB RAM) (Lấy từ kết quả JSON trả về của API, ví dụ: 2 CPUs, 4 GB RAM)
Hệ điều hành Windows 11 Linux (Ubuntu / Debian)
Cách truy cập từ thiết bị khác Phức tạp (Cần cấu hình mạng LAN / Port Forwarding) Đơn giản qua URL Public (Port Visibility)
Chi phí, đo bằng gì Chi phí mua phần cứng ban đầu Đo bằng số lượng core-giờ (Core-hours) trong Billing

2. Đối chiếu 5 đặc tính điện toán đám mây của NIST

  • On-demand self-service (Tự phục vụ theo yêu cầu): Tự khởi tạo máy ảo Codespace qua giao diện web mà không cần thông qua quản trị viên hệ thống.
  • Broad network access (Truy cập mạng rộng): Triển khai API và truy cập linh hoạt từ xa thông qua điện thoại và máy tính qua Internet.
  • Resource pooling (Gộp tài nguyên): Máy ảo chạy trên cụm hạ tầng phần cứng ảo hóa dùng chung của GitHub/Microsoft.
  • Rapid elasticity (Co giãn nhanh): Dễ dàng bật/tắt hoặc thay đổi tài nguyên máy ảo ngay lập tức khi có nhu cầu.
  • Measured service (Dịch vụ đo lường được): Theo dõi sát sao dung lượng tiêu thụ và thời gian sử dụng tài nguyên (Core-hours) trong mục Billing.
